# TypeScript Design Patterns

Udemy 講座「TypeScript デザインパターン」の学習教材リポジトリ。

## フォルダ構成

```
.
├── 01-setup/                # 環境構築・基本セットアップ
├── 02-uml/                  # UML 図の読み方・作り方
├── 03-solid-principle/      # SOLID 原則
├── 04-design-pattern-part1/ # デザインパターン前半
├── 05-design-pattern-part2/ # デザインパターン中盤
├── 06-design-pattern-part3/ # デザインパターン後半
├── sections/                # 講座の進行スナップショット
│   ├── section2/
│   ├── section3/
│   ├── section4/
│   ├── section5/
│   └── section6/
├── package.json
├── tsconfig.json
└── jest.config.js
```

## sections/ について

`sections/section2` 〜 `sections/section6` は講座を進めるにつれての途中状態スナップショット。
各セクション完了時点のプロジェクト全体が格納されている。

## セットアップ

```bash
npm install
npm test
```
